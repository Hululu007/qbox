# QBox 项目金标准（GOLDEN STANDARDS）

> 用途：防倒退。改本项目（`fongmi-561/`）任何 UI/交互代码前必读；每条含规则、反例、验证、来源。
> 级别：**Blocker（不可违反）** / 应当遵守 / 建议。Blocker 违反 = 直接打回。
> 问题编号（N-xx/P1/D2/A2/H-xx）详见 `uiux-review-log.md` 与 `ui-ux-audit.md`；commit 哈希属 `fongmi-561` 仓。
> 每次修复引入新教训时，回流一条规则到本文件（见 §七）。

## 一、硬约束（Blocker，不可违反）

- **GS-01｜色彩 ≤3**：交互态全部由中性色（黑/白/灰阶）承担；品牌蓝仅留 logo、设置分区竖条、链接语义。
  反例：N-37 进度条蓝 `#FF4C8DFF`、左上蓝紫柔光 `#332B4A74`、对话框链接黄、Material 蓝控件并存（用户：颜色乱）。｜验证：全仓扫描 hex 与 `qbox_accent` 引用，逐条对 token。｜来源：N-37/N-38，`79753d3`
- **GS-02｜单一圆角与尺寸 token**：圆角、间距、头部尺寸只取 `dimens.xml` 既有 token，禁页面级硬编码新值。
  反例：1.9.7 前头部尺寸散落各处，进分类页框架位移。｜验证：diff 中出现新 dp 字面量须能指出对应 token 理由。｜来源：1.9.7 收口
- **GS-03｜按钮定宽/定槽位**：取值型按钮（片头/片尾/倍速等）槽位宽度固定，文字变化不得推挤相邻按钮。
  反例：片头片尾按钮随秒数 `0:00`→`12:34` 变宽、整行跳动；R25-01 顶栏胶囊展开推左搜索图标 70–93px。｜验证：设值前后连截两图，对比同排按钮 bounds。｜来源：用户反馈 + R25-01
- **GS-04｜禁聚焦改变布局尺寸**：聚焦表达用 `scale`（统一 `ZOOM_FACTOR_SMALL`），禁改 padding/margin/layout。
  反例：N-33 聚焦行独占 padding，聚焦时文字右移、行高跳动。｜验证：焦点进出时截屏对比同行文字 x 坐标与行高。｜来源：N-33，`8d153fe`
- **GS-05｜三态只变 1–2 个属性**：普通/焦点/激活三态仅组合「底衬、描边、字色」中 1–2 项，禁全套换装；且必须形态+颜色双通道，禁只靠颜色。
  反例：N-28 循环开态仅 12% 白底≈不可见，用户不知循环已开。｜验证：三态两两截图可一眼区分（10 英尺距离）。｜来源：N-28 切换按钮规则
- **GS-06｜弹层一律公共组件**：所有底部弹层/对话框走统一面板（`qbox_surface` 深色基调 + `ThemeOverlay.QBox.Sheet/Dialog`，关 Material elevation 叠色），禁裸 Material 主题。
  反例：N-36 音轨/画质面板紫灰叠色+蓝控件，「像另一套 UI」。｜验证：新增弹层截图与「选择音轨」面板并排对比。｜来源：N-36，`79753d3`
- **GS-07｜手动操作优先于自动逻辑**：自动换源/换线必须有上限（现行：连续 3 次）且让位于手动选择；超限后界面稳定停在当前态。
  反例：N-45 未登录网盘连续报错自动换源连跳，焦点一直被抢、手动抢不过。｜验证：构造连续失败场景，数换源次数并确认焦点不被抢。｜来源：N-45，`f5cc81e`
- **GS-08｜禁改 Leanback RecyclerView 父子层级**：不得为加装饰/渐隐而包裹或改其父容器（`setHeader` 等依赖直接父子关系）。
  反例：`5f1b1c7` FrameLayout 包裹站点 tab 行 → 搜索页整页空白（N-19），已 revert。｜验证：改后搜索页/分类页整页截图非空白。｜来源：N-13/N-19，`5fd8f55`
- **GS-09｜验证手段铁律**：5s 自动收起 UI 的验证序列必须放在**单条 adb shell** 内；uiautomator 的 `focused`/`bounds` 对 SurfaceView/Leanback 常返回旧值，**以截图视觉+行为（position 是否跳变）交叉验证**；无法验证的项标 blocked 不许标 fixed。
  反例：N-24 初验误判失败（命令往返超 5s 窗口）。｜来源：第 10 轮方法学教训
- **GS-10｜工具纪律**：禁 `adb uninstall`（只 `install -r`）；禁 PowerShell `Set-Content` 写 XML/Java（BOM 会炸资源合并与 javac），一律用 Write/Edit 工具。
  反例：2026-11-04 误 uninstall 清空测试机数据；`dialog_player_engine.xml` 带 BOM 资源合并失败。｜来源：§3.5 误操作记录、第 15 轮教训
- **GS-35｜D-pad 全可达与返回链（TV-01/TV-06/TV-10/TV-11，Play TV 质量硬性）**：所有可见可交互控件五向 D-pad 可达可选、无焦点陷阱/凭空跳屏；返回键逐级回退直至桌面，禁退出确认弹窗、禁返回死循环、屏幕不画虚拟返回按钮；任何功能不得只能依赖菜单键触达。
  验证：`input keyevent 19/20/21/22` 遍历 + `uiautomator dump` 看 `focused` 落点；连按 BACK 用 `dumpsys activity activities` 观栈到 launcher。｜来源：TV 标准（tv-design-standard）硬性项并入

## 二、布局与对齐（应当遵守）

- **GS-11｜8dp 栅格**：间距与内边距取 8 的倍数；新间距先入 `dimens.xml`。
  验证：截图测距抽查。｜来源：§5 间距收口
- **GS-12｜bounds 一致性**：同一组件在不同页面/状态 bounds 一致；改动后用 dump+截图双路比对（注意 GS-09 旧值陷阱）。
  来源：A2 排行榜首项、1.9.10 第一排焦点环被裁
- **GS-13｜状态枚举法**：凡显示文案/数字处，必须枚举验证 0/1/2/3 位数、`99+`、超长文案、空值/占位。
  反例：片头 `09:12` 撑宽按钮；个别源海报占位图被当内容（N-14）。｜验证：构造极端值逐项过。｜来源：N-14、GS-03
- **GS-14｜顶栏槽位固定**：顶栏图标/胶囊聚焦展开不得推挤相邻元素（固定槽位或容器左对齐，二选一后全站统一）。
  来源：R25-01（方案待拍板，新改动不得再恶化）
- **GS-33｜禁止单控件固定 dp 解决抖动**：行内按钮尺寸跳变的唯一合法解法是**整行等分**（`layout_width=0dp + layout_weight=1`，文字居中+tnum+ellipsize）；给单个控件定死 dp 宽度会把该行变成「有的宽有的窄」（反例：第 16 轮 Control.Value 76dp 使片头/片尾/倍速比邻键宽一圈，被用户打回）。数量变化由 GONE/权重天然自适应；放不下才收「更多」（恒为最后一个）。验证：改后量各按钮 bounds，宽度差 ≤1px、行右缘与进度条容器右缘对齐、无滚动。｜来源：第 16→17 轮返工
- **GS-32｜弹层窗口防假安全区**：弹层窗口必须 `layoutInDisplayCutoutMode=ALWAYS`（与主窗口一致）；BottomSheet 另需吃掉 sheet 的 inset 分发并在每次布局强制 margin 归零（`BaseBottomSheetDialog.fixSheetFrame`，勿删）。
  反例：本机（IP810N）上报假左侧系统 inset 320px，Material `marginLeftSystemWindowInsets` 转成 sheet marginLeft → 面板偏右 ~400dp 宽、右缘被裁（sheet=[720..1520] vs 窗口=[400..1520]）。｜验证：弹层打开后 uiautomator dump，`design_bottom_sheet` bounds == 窗口 bounds；或截图像素扫描面板左右边。｜来源：第 16 轮面板化

## 三、焦点与场景（应当遵守）

- **GS-15｜弹层打开即有可见焦点**：对话框/面板打开后焦点落到具体项；`scrollToPosition` 不等于焦点。
  反例：N-34 直播/站点配置对话框无焦点，用户不知当前项；P1 恢复对话框焦点滞留设置页。｜验证：打开即截图，焦点 pill 可见。｜来源：N-34/P1，`8d153fe`
- **GS-16｜duplicateParentState 陷阱**：自身可聚焦的 View 禁用 `duplicateParentState`（焦点在但焦点态不渲染）；仅当父容器承载焦点态时使用。
  反例：P1 族（`adapter_live`/`adapter_config`/`adapter_restore`/`dialog_player_engine`）焦点在但白 pill 不渲染；D2 设置行焦点不可见。｜验证：新增列表项 grep 确认无该属性，焦点态截图。｜来源：P1 族/D2，`3713668`
- **GS-17｜焦点请求等布局完成**：`requestFocus` 必须在布局完成后（`OnGlobalLayoutListener`/`post`），同步调用必败（`isShown()==false`）。
  反例：N-24 控制条呼出后焦点留在 video，→/← 被当快进，14 个按钮全不可达。｜验证：呼出控制条 → → 为行内移动、position 不跳变。｜来源：N-24，`ea3947a`/`b9c8590`
- **GS-18｜列表首/末/边缘必验**：列表首项、末项、贴边项实机验证焦点环完整、不被裁切。
  反例：1.9.10 裁切线 120dp 正好压在第一排焦点环顶边；A2 排行榜首项。｜验证：首项聚焦四边环完整截图。｜来源：1.9.10，A2
- **GS-19｜焦点不被自动逻辑抢走**：换源/换线/刷新/计时器等自动动作不得改变用户当前焦点。
  来源：N-45（同 GS-07 根因，聚焦面单列）
- **GS-36｜任意时刻唯一可见焦点 + 方向与视觉一致（TV-02/TV-06）**：每页有且只有一个明确可见焦点元素（含启动后、闲置后、数据刷新后）；四方向焦点移动与视觉方位一致可预测，不可达控件改位置而不是藏。
  验证：每页 dump 后 `focused="true"` 计数为 1 且截图焦点态可见；四方向走查记录焦点路径。｜来源：TV 标准并入

## 四、视觉与图像（应当遵守）

- **GS-20｜模糊底图取中心横带**：氛围底图取源海报中心 16:9 横带（`override(160,90)`，~12× 放大），禁小方块高倍放大、禁取单边。
  反例：N-39 40×40 中心方块 48× 放大只剩色块；用户反馈「取单边」。｜验证：底图可辨识画面内容。｜来源：N-39，`79753d3`
- **GS-21｜焦点环不被裁切/遮盖**：焦点环放独立覆盖层，位于遮罩/压暗层之上，四边全程完整。
  反例：N-41 最近观看焦点框下半圈被卡片底部压暗遮罩吃掉。｜验证：聚焦卡片截图看四边环。｜来源：N-41，`79753d3`
- **GS-22｜渐变压暗只用单向线性**：禁圆心在角落的大半径径向渐变叠深色底。
  反例：N-32 直播列表左上黑块（380dp 径向渐变叠 94% 黑底）。｜验证：列表首行可读截图。｜来源：N-32，`8d153fe`
- **GS-23｜文本防豆腐块**：站点名/用户生成文本统一走 `Util.cleanName`（`Paint.hasGlyph` 检查，含 BMP 符号区 0x2190–0x2BFF）。
  反例：N-35 站点名 ♥⭐▶ 在精简字体盒子上显示豆腐块。｜验证：换缺字形机型/字体截图。｜来源：N-35，`8d153fe`
- **GS-24｜海报中心裁切 + 失败占位**：海报 `centerCrop`；封面加载失败/空图必须有占位且可辨识为占位（非内容）。
  反例：P2 封面加载问题；N-14 源侧占位深色块。｜验证：断网/坏图场景截图。｜来源：P2、N-14
- **GS-37｜过扫安全区 5%（TV-22）**：关键内容（标题/按钮/焦点环）不踏入四边 5% 过扫区——960×540dp 基准下侧边 ≈48–58dp、上下 ≈27–28dp（官方页两组数字并存，取保守值）；背景/氛围底图出血铺满、不进安全区。
  验证：720p 老盒子截屏量关键元素到四边距离。｜来源：TV 标准并入
- **GS-38｜文字可读性（TV-30/TV-31/TV-33/TV-34）**：字号一律 sp、尊重系统 font_scale（1.3 倍不截断不出屏）；禁 Ultralight/Thin/Light 细字重，正文标签 Regular 起步、远距离优先 Medium；正文对比度 ≥4.5:1、大字号 ≥3:1（**数值出自 WCAG，非 TV 官方**，TV 官方仅方向性要求；本项目 `qbox_text_mute` 已 5.9:1，1.9.9）。
  验证：`settings put system font_scale 1.3` 逐页截图；截屏取色算对比度。｜来源：TV 标准并入
- **GS-39｜图片压文字必须有 scrim（TV-35）+ 卡片比例取舍（TV-52）**：海报/剧照上压文字必须加半透明渐变 scrim。官方建议卡片只用 16:9/1:1/2:3 三种宽高比——**取舍：本项目海报沿用 3:4**（FongMi 生态片源比例，内容驱动，且全站统一），新增卡片形态时优先官方三档。
  来源：TV 标准并入（冲突项按项目实际取舍）
- **GS-40｜氛围色走「基于内容」取色（TV-41）**：TV 无壁纸动态取色（系统只广播基础调色板）；本项目海报氛围底图（GS-20）即合规的「基于内容」路径，禁引入伪壁纸取色方案；高亮/焦点色收敛一套 token（TV-42，GS-01 已覆盖）。
  来源：TV 标准并入

## 五、交互与守卫（应当遵守）

- **GS-25｜长按/短按判定**：`dispatchKeyEvent` 全局拦截必须为「列表可见」场景放行 `OnLongClick`；拦截范围按可见性守卫。
  反例：N-31 TV 端长按 OK 被全局拦截开控制条，频道长按收藏永远不可达。｜验证：列表展开时长按收藏生效、收起时长按开控制条。｜来源：N-31，`4d692ad`
- **GS-26｜配置失败兜底**：配置首载失败（内存与缓存均无站点）回退内置快照；禁裸「获取失败」卡死用户。
  反例：N-46「获取失败 xiuxiu pro」配置失效后卡报错页。｜验证：配置失效地址首载，验证回退路径（debug/release 行为差异须知晓）。｜来源：N-46，`f5cc81e`
- **GS-27｜未登录不自动动作**：未登录/未授权（网盘等）只提示引导，不触发自动换源/自动重试连跳。
  来源：N-45/N-44；GS-07 的具体化
- **GS-28｜错误态/空态/加载态三态统一**：统一组件与文案；空面板必须有占位文案（如「暂无可用字幕」）。
  反例：N-27 空字幕面板无占位；H-23 各页三态各写各的。｜验证：空/错/加载三态截图齐。｜来源：N-27、H-23
- **GS-29｜点击无反应先查源侧**：站点为加固 spider（`csp_*Guard`）时点击无响应先查 logcat 是否真实发出请求，勿当 UI bug 改布局。
  反例：N-44 网盘管理「点击无反应」，实为 spider 请求路径，当前构建未复现。｜验证：`logcat | grep spider` 类证据先行。｜来源：N-44
- **GS-30｜开关/取值型状态持久化**：循环、倍速等状态写 `Prefers`，重进页面与重启后恢复；面板选择型状态标记在面板内。
  验证：force-stop 重启后状态保持（N-28 已实证）。｜来源：N-28，`aa566e8`
- **GS-31｜异常流守卫（建议）**：ENDED/buffering 态下方向键与切线需有守卫或引导，不死停 00:00。
  来源：N-30（open，修复时按此验收）
- **GS-34｜可调值/选择类两类交互 + 防串键**：可调值类（倍速/片头/片尾，CustomUpDownView）支持 **↑/↓ 就地调档（即时、不弹窗、不动焦点）+ OK 开面板**；选择类（缩放/解码/引擎/线路/章节/音轨/字幕/视轨）**只认点击，↑/↓ 一律消费且无副作用**。防串键必须在按键分发层 consume（`CustomUpDownView.dispatchKeyEvent` + Activity `onControlKey` 对非 UpDown 焦点直接 return true），不得依赖控件"看运气"没把事件传出去。例外：extra 行内 ↓ 回主行「更多」（纯导航，否则焦点困死）。
  反例：旧实现 ↑ 从任意按钮跳进度条——焦点在音轨上按 ↑ 会进 scrub 态（误触源）；GS-33 教训同期。｜验证：暂停态聚焦倍速按 ↑/↓，position/exo position 纹丝不动仅档位变；焦点在音轨按 ↑/↓ 值不变、焦点不动。｜来源：第 17 轮
- **GS-41｜播放器遥控与电源语义（TV-12/TV-13/TV-14/TV-62/TV-63/TV-65/TV-66）**：播放中 D-pad 中键=暂停/恢复并呼出控制条，媒体键 PLAY_PAUSE 必切播放态；切后台视频必须暂停；起播零阻碍（选片/深链直达，不插屏、不弹「是否续播」确认，自动续播，>2s 给黑底居中加载）；退出播放回详情页（含续播入口），不丢用户到无关页；播放中阻止休眠，暂停/非播放不得阻止；记忆播放位置 + 卡片进度条（1.9.2 已落地）。
  验证：播放态 `input keyevent 23/85`；播放中 HOME 后 `dumpsys media_session`；冷起点播计时。｜来源：TV 标准并入
- **GS-42｜【有意偏离】阶梯快进（对 TV-13「左右单按固定秒数」）**：官方建议单按固定秒数，本项目保留 10→20→30→60→120→180→300s 阶梯加速（1.9.10/1.9.11，300ms 节流）——**取舍理由：长片盲操效率优先，且复用底部控制条进度实时可见**。改进方向=加速起档前延长细调窗口（首档 10s 停留更久再升档），细调精度与加速效率兼得。
  验证：GS-09 单条 adb shell 时序 + position 跳变交叉验证。｜来源：第 17 轮复测 + TV 标准取舍登记
- **GS-43｜三态恢复路径（TV-70/TV-71/TV-72，细化 GS-28）**：加载先给占位（骨架/占位图文）非白屏，长等待给进度指示；空态说明原因并给可聚焦的下一步操作；断网/加载失败给可聚焦「重试」，禁只弹一闪而过 toast；空 tab 保留并解释，不隐藏。
  来源：TV 标准并入
- **GS-44｜语音搜索入口常驻（TV-88）**：搜索提供语音输入路径；设备无语音服务时入口保留、压暗并提示，不隐藏（1.9.10 已落地，本条作防倒退登记）。
  来源：TV 标准并入
- **GS-45｜无障碍标签与音频说明（TV-80/TV-81）**：每个可交互元素有 contentDescription（图标按钮不能只给图形，1.9.9 已补 6 处）；API 33+ 查询并响应系统「音频说明」偏好（isAudioDescriptionRequested）——**当前未实现，登记为 open 项**。
  验证：dump 查 `content-desc` 非空。｜来源：TV 标准并入
