# QBox 2.0.0

发布日期：2026-11-16

这是 QBox 的**播放内核大对齐**版本。

## 重点

- 播放内核与 App 层对齐到 **FongMi/TV 5.6.1（`125468f0`，2026-08-27）**，拿到上游完整的 Controller / State / Request / Preloader / 播放守卫能力。
- **media 层不动**：继续使用 `release-1.11.0-fongmi` 的 media3 **1.11.0** 自编 AAR，不升级媒体层。
- 起播位置按请求固定：切集、开播前写播放记录不再污染新集起点。
- 片尾跳集守卫：`duration` 未就绪或没有在播请求时不会误触发自动下一集。
- QBox 壳子保持不变：遥控器优先、两排选集网格、点集预览、换源、控制栏、收藏/历史等交互继续可用。
- 升级检查继续指向本仓库 GitHub Releases；老客户端可以直接点「更新」覆盖安装。

上游来源与改动范围见 [`docs/UPSTREAM.md`](UPSTREAM.md)。

## 实机验收

在 Android 9 / 1080p / armeabi-v7a 测试盒上完成：

- 两条线路点集
- 切集、重启后续播
- 片尾 / 自动下一集
- 换源
- 媒体键（暂停/播放/播放暂停）
- 后台暂停与位置保持
- 720p 覆盖布局

未覆盖：换清晰度（源只返回单 URL，网盘源需扫码登录）、真正 720p 硬件、部分设备的 30 集末组翻页边界、4K/DV 角标。

## 升级说明

- `versionCode 100` / `versionName 2.0.0`，高于 1.9.24 的 `82`。
- 1.9.13 及之后版本使用同一签名，可直接覆盖安装，配置、播放记录、收藏保留。
- 老客户端启动弹窗或「设置 → 版本」检查更新，点「更新」即可下载并安装 2.0.0。
- 2026-11-16 已在 Android 9 / armeabi-v7a 测试盒上从 1.9.24 实机走通：启动弹窗检测到 v2.0.0 → 点「更新」→ 自动下载并覆盖安装 → 包版本变为 `100 / 2.0.0`，手动打开 QBox 后首页与「最近观看」保留。安装完成后系统回到桌面，不会自动拉起 QBox。
- 如果设备无法访问 GitHub，可手动下载本 Release 的 `QBox-2.0.0-armeabi-v7a.apk`（老盒子）或 `QBox-2.0.0-arm64-v8a.apk`（64 位盒子）。
