# QBox 电视端验收清单

> 目标：确认「配置载入 → 站点浏览 → 详情 → 播放」与直播链路在真机上成立。
> 当前包：`QBox-1.3.1-arm64-v8a.apk` / `QBox-1.3.1-armeabi-v7a.apk`（`applicationId com.qbox.app`，minSdk 24）。

## 0. 安装

- 主流电视/盒子（64 位）用 arm64 包；老设备用 armeabi-v7a 包。
- 安装后桌面图标为深色圆角 + 白色环形播放标记，名称 **QBox**。

## 1. 自检（先做这一步，30 秒）

首页标题「QBox」上 **长按遥控器 OK**，应弹出「QBox 自检」：

```
版本：1.3.x
配置：老白TVBOX
地址：https://tvbox.laobaitv.net
站点：49
直播：6
jar 缓存：N 个文件
spider：…/e05f….jpg;md5;b55978c4…
```

| 观察点 | 通过标准 | 失败含义 |
|---|---|---|
| `站点` | 49（或接近 49） | 配置没载入 / 解析失败 |
| `直播` | 6 | 直播配置缺失 |
| `jar 缓存` | ≥ 1 | 爬虫 jar 没下载（网络或 md5 校验失败） |
| `spider` | 以 `.jpg;md5;` 结尾 | 配置的 spider 字段异常 |

只要 `站点` 是 49，就说明「壳成功载入测试源」这条已经过了。

## 2. 点播链路

1. 首页往下找到「站点/推荐」行 → 选任意站点（如「厂长」「瓜子」）→ OK；
2. 进入分类页：左侧分类、右侧海报网格应出图；
3. 选一部影片 → 详情页显示简介、线路、剧集；
4. 选第一集 → 应进入播放（黑屏后出画面/声音）。

通过标准：能出海报、能进详情、能起播。
失败时记录：卡在哪一步、是否有 Toast、是否黑屏、是否有声音。

## 3. 直播链路

1. 首页功能区进「直播」（或菜单里的直播入口）；
2. 频道列表应出现分组（综合直播 / 虎牙 / 斗鱼 / YY 等）；
3. 选一个频道 → 应起播。

通过标准：频道列表有内容、选台能起播。

## 4. 配置切换

设置 → 配置地址：应显示 `https://tvbox.laobaitv.net`；可粘贴其他 TVBox 配置地址测试切换。

## 5. 报告方式

把以下信息发我即可定位：

- 自检对话框截图（最重要）；
- 卡住步骤的截图或一句话描述；
- 电视型号 / Android 版本；
- 如果是播放问题：用的是 ExoPlayer 还是 MPV（设置 → 播放器）。

## 已知不可用（不用报）

- `py` 类型站点（Python 运行时已裁掉，会回退空实现）；
- 解码模式 FFMPEG（未编译，选 MPV 或硬解）；
- 在线更新检查（已改为提示手动下载）。
