# QBox UI 设计方向（v1 提案）

目标：在 FongMi/TV 5.6.1 的能力之上，把界面做成"自己的壳"——参考 Apple TV+ / Netflix 的留白与聚焦感，
但保持电视遥控器的焦点逻辑与性能（不引入 Compose）。

预览图：[ui-home-mock.png](ui-home-mock.png)（1920×1080，由脚本生成，仅表达布局/层级/配色）

## 设计 token

| Token | 值 | 用途 |
|---|---|---|
| `qbox_bg` | `#0B0B0F` | 全屏背景 |
| `surface` | `#18181E` | 卡片、hero |
| `surface_hi` | `#24242C` | 选中态、浮层 |
| `text` | `#E8E8EC` | 主文字 |
| `text_dim` | `#9696A0` | 次要信息 |
| `accent` | `#4C8DFF` | 主按钮、进度、焦点辅助 |
| 焦点 | 白色 3–4dp 描边 + 1.03 缩放 | 所有可聚焦卡片 |
| 圆角 | 卡片 14dp / 大面板 22dp / 药丸 999dp | 统一 |

字体沿用系统（思源/微软雅黑），标题加粗、正文常规；电视端字号下限 16sp，主要标题 24–32sp。

## 首页（对应 `activity_home.xml`）

1. **顶栏**：左 QBox 标记 + 字标；右侧 tab `首页 / 直播 / 设置`，选中为白色药丸（深色文字）。
2. **Hero**：当前配置名（如"老白TVBOX"）+ 一行状态（N 个站点 · M 路直播 · 默认配置已载入）+
   主按钮「继续观看」（有历史时）与「搜索」。
3. **站点区**：标题 + "全部 ›"，6 列海报网格（2:3），卡片含名称、备注（画质/更新），焦点白环。
4. 后续可加「最近更新」「收藏」横向行（用 homeContent 的 list / Room 历史）。

## 点播页（对应 `activity_vod.xml`）

- 顶部面包屑：站点名 + 当前分类 + 筛选入口。
- 左侧 180dp 分类栏（焦点态：亮条 + 白字），右侧 6 列海报网格；筛选（类型/地区/年份）以 chip 行置于网格上方。
- 滚动到底自动翻页保留 FongMi 现有逻辑。

## 详情/播放（对应 `activity_video.xml`）

- 上半屏 hero：背景剧照 + 标题/评分/年份/地区 + 简介 3 行折叠 + 主按钮「播放」/「收藏」。
- 下半屏：线路切换 chips + 剧集网格（横向滚动），当前集高亮。
- 播放仍为全屏 OSD，保留 FongMi 的选轨/字幕/倍速。

## 实施顺序（低风险优先）

1. ✅ 颜色/圆角/焦点样式统一（1.1.0）：焦点环 3dp、卡片圆角 12dp、主色 `#4C8DFF`、首页标题栏 32dp 边距 + 56dp logo + 28sp 标题。
2. ✅ 首页 hero + tab：**已合并并随 1.4.0 发布，真机验证通过**。历史：实验分支 `ui-hero` 实现（hero 显示配置名/站点数/直播数，三 tab 分别回顶、进直播、进设置），出包 `v1.4.0-hero`（pre-release）。主干仍是 1.3.2，等真机对比后再决定合并或放弃。新增 `HomeLayoutTest` 冒烟验证（应用主题下 hero 可 inflate、tab 可聚焦，输出 `QBOX_UI_OK`）。
3. 海报卡样式（`item_*` 布局）与网格列数自适应（按屏幕宽度 5–7 列）。
4. 点播页分类栏与筛选 chips。
5. 详情页 hero 布局。
6. 每步出 APK 交真机验收，避免一次性大改。

> 2 及以后需要真机基线：先在电视上确认 1.1.0 加载/播放正常，再动布局结构。
