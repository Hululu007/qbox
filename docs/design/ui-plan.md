# QBox UI 设计系统：Cinema（2026-10）

> 取代早期 1.1.0/1.4.0 的 hero + 三 tab 提案。当前目标是 **Infuse / Netflix 式的高級簡約**：
> 纯黑画布、单色文字、克制的品牌蓝，只靠留白、字重和焦点态建立层次。
> 不引入 Compose，保留 FongMi leanback 的遥控器焦点链路。

真机截图：`docs/screenshots/ui-cinema/`（JmGO 投影，1920×1080 @320dpi）：
`v190-home` / `v190-home-toolbar` / `v190-vod` / `v190-vod-filter` / `v190-detail` /
`v190-detail-episodes` / `v190-osd` / `v190-osd-more` / `v190-stats` / `v190-search` /
`v190-live-list` / `v190-settings`。

## 1. Token

| Token | 值 | 用途 |
|---|---|---|
| `qbox_bg` | `#000000` | 全屏画布（纯黑，不再用 `#0B0B0F`） |
| `qbox_line` | 白 12% | 细分隔线 |
| `qbox_text` | `#FFFFFF` | 标题、主文字 |
| `qbox_text_dim` | `#B9B9C4` | 次要信息（年份/地区/时钟） |
| `qbox_text_mute` | `#8A8A96` | 说明文字（导演/演员/简介） |
| `qbox_accent` | `#5B8CFF` | 进度、选中环、链接；**不用于大面积填充** |
| `qbox_focus_text` | `#0B0B0F` | 白药丸/白环上的文字 |

规则：

- 焦点 = **白色药丸/白环**（反色），文字变深；选中 = 2dp 蓝色环。
- 卡片圆角 12dp，海报 10dp，面板 14dp；焦点环 2dp（不再 3–4dp + 缩放）。
- 图标与文字同色（`app:tint="@color/text"`，selector 内含 focused → 深色）。
- 字号：页面标题 19sp 粗体、详情标题 32sp 粗体、行标题 21sp、正文 14–15sp、tab 17sp、时钟 15sp（`tnum`）。

## 2. 全局外壳

所有二级页面统一顶栏：`46dp 圆形返回箭头 + 19sp 粗体标题 + 右侧 dim 时钟`。

- 返回箭头：`ic_back.xml` + `selector_action_icon`（焦点变白底深色）。
- 时钟：`HH:mm` / `HH:mm MM/dd EEE`，`fontFeatureSettings="tnum"`，不再带背景板。
- 首页顶栏：logo + **配置名药丸**（点击换源、长按直接换配置）+ 右侧 5 个 46dp 圆形图标
  （搜索 / 直播 / 收藏 / 推送 / 设置）+ 时钟。**图标默认只显示图形，聚焦时在下方显示 11sp 文字说明**
  （标签行固定 14dp 高，出现/消失不引起跳动）。

## 3. 首页

- 导航行：**只列当前源的点播分类**（不再有「首页」占位 tab；它就是首页）。
  tab 为纯文字 + 2dp 白色下划线，只响应焦点（不显示"当前分类"），点击进入点播分类页。
- 内容行：`最近观看`（历史，带进度条）→ `推荐`（网格）。行标题 21sp 粗体，与内容左对齐 40dp。
- 海报卡：海报 + 左对齐标题 + 一行灰色元信息（年份 · 备注，合并成一行），
  不再叠加彩色年份/评分/更新角标；焦点 2dp 白环。

## 4. 点播分类页

- 顶栏：返回 + 站点名 + **筛选药丸**（无筛选项时隐藏）+ 时钟。
- 分类 tab：`首页` + 各分类，50dp 高、2dp 白色下划线。再次按当前分类 = 展开/收起筛选；
  筛选也可以直接点顶栏药丸。菜单键同样切换筛选。
- 筛选行：chip 式纯文字，选中白字，未选 dim。
- 内容：5 列海报网格（`Product.getColumn`），滚动到底自动翻页。
- **分类 tab 常驻**：不再被内容网格当作 sticky header 隐藏（`TypeFragment` 不再 `setHeader`）。

## 5. 详情 / 播放

- 左侧 400×225dp 视频框（焦点可进入→全屏），右侧：32sp 标题、备注、
  `站点 · 年份 · 地区 · 类型` 合并 meta、`导演 ·` `演员 ·`、简介（最多 5 行）。
- 主操作行：白色「播放」药丸 + 简介 / 收藏 / 换源（暗色药丸）。
- 下方：线路 flag、清晰度、剧集、分段、快速搜索，均为横向列表。
- 详情页根布局为纯黑背景，不露出壁纸。

## 6. 播放 OSD

控制条只保留 **一屏放得下** 的常用项，其余收进「更多」，彻底去掉横向滚动：

```
标题
进度条（品牌蓝）
[选集] [倍速] [音轨] [字幕] [详情] [更多]      ← 常用行
```

- 点「更多」在常用行上方展开两行次级开关：`下集 上集 原始 视轨 硬解 EXO` /
  `刷新 片头 片尾 循环 重播`，按钮文字变「收起」。
- 焦点规则：进度条 ↓ → 常用行首项；次级行 ↓ → 常用行；常用行 ↓ 不越界。
  打开控制条时若目标项在次级行，会自动展开。
- 「详情」= Stats for nerds 面板（左上角，1s 刷新，再按一次关闭）：

```
QBox stats
Engine   EXO · 硬解 · Surface
State    PLAYING · 1.0x
Video    1440×810 · 25.00fps · SDR
Codec    avc1.640020 · 4.20 Mbps
Audio    mp4a.40.2 · 2ch · 44.1kHz · Passthrough
Output   Passthrough · Dolby Digital+
Net      8.4 MB/s
Buffer   12.3s
Source   cdn.example.com
```

- 加载态中央转圈下方显示实时带宽（`Traffic`），不再隐藏。
- 弹幕：入口与云搜全部移除（`loadDanmaku` 空实现，设置页入口隐藏）。

## 7. 其他页面

- 搜索：64dp 圆角搜索框、dim 分区标题、站点 chip 行（选中下划线），结果复用海报卡。
- 收藏：顶栏 + 结果标题 + 网格，进入后焦点直接落到第一张卡。
- 直播：左侧频道分组/列表改为单色，选中行为白药丸，数字键选台保留。
- 设置：分组卡片、12dp 行距、图标 `app:tint`；弹幕项隐藏。

## 8. 已知取舍

- 不使用 Compose / 动画库，转场仍交给系统，避免低端盒子掉帧。
- 首页没有 hero 大图：源的内容结构不稳定，hero 容易空窗；用「最近观看」承担"继续观看"入口。
- 焦点态统一"反色药丸"，所以任何使用 `@color/text` 的控件必须同时挂
  `selector_item*` / `selector_chip*` / `selector_tab` 背景，否则白字会看不见。
