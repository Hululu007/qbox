### 1.9.3 增补（720p 机顶盒适配 + 细节修正）
- **顶部渐隐误伤第一行标题（修）**：Leanback 首行会有 1px 亚像素偏移，
  `top < paddingTop` 直接判定「已滚动」，入口页第一行标题被 88dp 渐隐整块盖住。
  改为留 6dp 容差（`ScrollUtil.isScrolledFromTop`），静止时渐变完全隐藏，滚动后才压暗。
- **站点名 emoji 豆腐块（修）**：源配置爱用 emoji / 图标字体装饰站点名，
  低端盒子（Android 9，字体不全）会渲染成 ▯。`Util.cleanName()` 用 `Paint.hasGlyph`
  逐字判断，渲染不出来的星平面字符、私有区字符、ZWJ/变体选择符直接去掉，
  站点名、卡片角标、聚合搜索 chip 全部走 `Site.getName()`，一处收口。
- **分类条高度写死 42dp**：配置还没拉回来时不再出现「整页内容先上移、数据到了再跳一下」。
- **搜索页可达性（修）**：搜索框按「下」进软键盘（RecyclerView 自身不可聚焦，
  原来的 `nextFocusDown` 指不过去，遥控器用户根本按不到字母键）；
  搜索框获得焦点时整条白描边（`selector_search_field` + 焦点监听），
  焦点进键盘后描边自动消失，不会同时出现两个焦点。
- **键盘图标反色（修）**：`adapter_keyboard_icon` 加 `app:tint="@color/text"`，
  白色药丸焦点下图标变深，不再「按键白底白图标」看不见。
- **详情页年份归一**：`1970-01-01`（源没给年份）直接丢弃，`2026-08-14` 只显示 `2026`。
- **对话框去紫灰**：Material3 默认按 elevation 给 surface 叠一层紫灰，换源/配置对话框比页面亮一档、
  偏紫。新增 `ThemeOverlay.QBox.Dialog`（`colorSurface` = `#17171C`、`elevationOverlayEnabled=false`），
  对话框回到和页面同一套近黑面板。
- 720p 机顶盒（1280×720 @160dpi）实测：5 列 3:4 海报、一屏 1.5 行，
  分类条 7 个分类、筛选药丸、聚合搜索结果页均正常。

### 1.9.9 增补（全量 review：对比度 / 二级页头部 / 聚焦反色）

按 ui-ux-pro-max 的 pro-rules 过了一遍：崩溃类问题没有，集中在「深色对比度」和「焦点态可读性」。

- **次要文字对比度不达标（修）**：`qbox_text_mute` `#70707A` 在黑画布上只有 **4.04:1**（surface 上 3.65:1），
  而它用在卡片备注（12sp）、分组标题（13sp）、搜索框 hint 上，全部低于 WCAG AA 的 4.5:1。
  改成 `#8C8C98`（黑底 5.9:1 / surface 5.2:1），信息层级不变，但客厅距离能看清。
- **二级设置页没有返回和标题（修）**：播放设置 / 解码设置 / 预载设置 / 弹幕设置四个页面原来是
  一屏裸列表，只能靠遥控器返回键退出。统一加 22dp 顶栏 + 46dp 返回按钮 + 20sp 标题，
  和主设置页同一套几何。
- **聚焦行白字看不见（修）**：这四个页面的行是白药丸焦点，但文字用的是 `@color/white`，
  聚焦后白底白字整行「消失」。全部改 `@color/text`（焦点态反色）+ `duplicateParentState`。
- **最近观看删除态遮罩塌陷（修）**：删除遮罩 `layout_alignBottom="@+id/remark"`，
  而删除态下 `remark` 是 GONE，遮罩高度算不出来 → 改成对齐父容器底部。
- **语音搜索图标没有焦点态**：36dp 图标直接可聚焦、没有描边；改 40dp + `selector_mic_focus`
  （聚焦白描边圆形底）+ contentDescription。
- **设置页 6 个图标补无障碍名称**（设为首页 / 播放记录 / 刷新），读屏不再是「按钮」。
- **硬编码色值收口**：`activity_video` 里的 `#B9B9C4` / `#0B0B0F` 换成 `qbox_text_dim` / `qbox_focus_text`。

### 1.9.8 增补（快进复用控制条 / 进度条焦点 / 搜索页间距）

- **左右快进复用控制条**：删掉 1.9.7 的独立浮层，左右快进时直接把底部控制条「借」出来显示
  （进度条 + 当前/总时长都在原位），焦点仍留在画面上，连续按左右可以一直快进；
  停手 1.8s 控制条自动收起。快进改为逐次 `seekTo`（`seekBase + 累计偏移`），进度条实时跟着走。
- **菜单按「上」进进度条**：控制条里按上不再卡在动作行，直接聚焦进度条（白色描边焦点框，
  `selector_seek_focus`），左右 ±10s、下键回动作行、OK 暂停/播放。
  焦点放在外层 `seek_box` 而不是 `PlayerSeekView` 本身，并在 buffering/ready 时回钉一次焦点，
  避免播放器状态变化把焦点甩回画面层。
- **搜索/聚合页 tab 与海报间距过大（修）**：`CollectFragment` 复用 `fragment_type.xml`，
  之前继承了点播页 144dp 的头部偏移，实际它的 pager 已经在头部下面 → 改 12dp
  （`qbox_content_top_inset`），也不再套用 120dp 的裁切线。
- **首页/点播首排焦点框被裁（修）**：内容起点 140→144dp，绘制裁切线 124→120dp（贴分类条下沿），
  给卡片聚焦放大（约 13dp）留出余量，首排白框完整显示。
- **详情页小窗直角**：`shape_video_bg` / `shape_video_focused` / `shape_video_normal` 去掉 12dp 圆角，
  `activity_video.xml` 去掉 `clipToOutline`。加载过程中不会再出现「圆角框 + 方形画面」的黑角缺口，
  全屏仍由 `setBackgroundColor(BLACK)` 保持纯黑黑边。

### 1.9.7 增补（Infuse 式底图 / 统一框架 / 播放黑边）

- **统一头部框架**：`dimens.xml` 新增 `qbox_header_pad_top`(22dp) / `qbox_header_content`(46dp) /
  `qbox_tabs_gap`(6dp) / `qbox_tabs_height`(42dp) / `qbox_content_top`(140dp)。
  首页、点播页、设置页、收藏、搜索全部用同一套数值，标题左边统一落在 96dp，
  从首页点进分类时上方整块框架不再「缩一下 / 上移一点」。
- **第一排不再被 tab 盖住**：`CustomVerticalGridView.setClipTop()` 在 124dp 处裁绘制，
  滚上去的卡片在分类条下沿被裁掉，既不会穿到 tab 下面（重影），也不会出现第一排上半截
  被压暗；因为只裁绘制、不动布局，焦点放大和 padding 都保持原样。
- **Infuse 式模糊海报底图**：首页/点播/详情统一用 40px 缩略图整屏 `centerCrop` 放大（等免费高斯模糊），
  底图 alpha 0.62 + `shape_backdrop_scrim` 改成 22%→35%→85% 的三段压暗，顶部只叠 40% 的
  `shape_top_scrim`。模糊海报的颜色真正透出来，顶栏文字仍然清晰。
- **详情页文字可读性**：亮色剧照上标题/导演/演员会糊，新增 `shape_detail_scrim` 横向渐变
  （左侧透明、右侧压到接近实底），左边留住海报色彩、右边保证 4.5:1 以上的对比。
- **播放黑边必须是黑的**：`enterFullscreen()` 由 `setBackground(null)` 改成
  `setBackgroundColor(BLACK)`。非 16:9 片源的上下/左右黑边是纯黑，不再透出氛围底图或页面渐变；
  片源比例仍由 `resize_mode=fit` 保持，不拉伸。
- **快进不再盲操作**：左右快进/快退时底部浮出「▶▶ 目标时间 / 总时长 + 进度条」
  （`view_widget_vod` 的 `seek_hint`），16dp 上浮 + 淡入 160ms，停手 1.6s 自动收起，
  与暂停/播放时的控制条互斥。
- **最近观看进度条去蓝**：改成白色 `progress_history`（35% 白圆角轨道 + 纯白填充），
  卡片底部加 56dp 压暗层，亮色剧照上也看得清；剧集列表进度条同步换掉主题蓝。
- **首页动作胶囊展开动画修复**：`GONE` 的 View 不会重新测量，`getMeasuredWidth()` 会保留
  上次展开后的宽度，导致 `from == to`、第二次展开没有动画。改为每次从 0 开始；
  收回仍然即时，不再挤动整排图标。
- **设置页两列**：内容源/播放在左，系统/维护在右，单条设置不再是 1200dp 的空长条；
  行高 5dp + 行距 6dp，720p 一屏放得下全部设置。

### 1.9.6 增补（滚动回顶 / 全屏 / 氛围背景）

- **分类页滚下去回不了第一行（修）**：`TypeFragment.isAtTop()` 原来只看 `getChildAt(0)` 的
  adapter position；RecyclerView 会保留视口外的 child，position 0 常驻，导致任何位置都判定「在顶部」，
  按 ↑ 直接跳回分类条。改为按第一个 child 的 `getTop()` 与 `paddingTop` 比较（8dp 容差），
  滚几行后 ↑ 逐行回退，真正到顶才回分类条。
- **首页胶囊收回不再抖**：`ActionChip` 只保留展开动画；失去焦点时宽度/文字立即归零，
  不再让上一颗胶囊边收边挤动整排图标。
- **全屏真四角**：`enterFullscreen()` 去掉详情态的 `shape_video_bg` 12dp 圆角背景与 `clipToOutline`，
  退出全屏再恢复；四角不再露出底色。
- **最近观看进度条**：进度条加粗到 4dp、左右缩进 8dp，蓝色进度 + 20% 白轨道，播放过的历史一眼能看到进度。
- **氛围底图改成整屏**：首页/点播页的 `backdrop` 从 460dp 顶部图改成 `match_parent` + `centerCrop`，
  配合整屏 `shape_backdrop_scrim` 与 140dp `shape_top_fade`，顶栏/分类条悬浮在海报模糊层上，
  滚动和切分类不再出现上下两块不同背景的硬切线。
- **点播页跟随焦点海报**：`VodActivity` 每 600ms 取当前焦点海报的 24px 缩略图做底图，
  切 tab / 移动焦点时背景跟着换；没有焦点海报时保持当前底图，不闪回推荐位。

### 1.9.5 增补（顶部黑块 / 动作按钮 / 播放条）

- **删掉顶部黑色隔断**：首页 88dp `topFade`、160dp `top_scrim` 和点播页 `topFade` 全部移除。
  之前内容只要滚动一点，就会有一整块不透明黑压下来，第一行被吞进黑色里、再也选不回去；
  现在滚动只是被内容区上边界自然裁切，第一行随时能滚回来，首页也多出一整行可见高度。
- **首页动作按钮改成「聚焦展开」**：搜索/直播/收藏/推送/设置静止态是 46dp 圆形图标，
  聚焦时横向展开成 icon + 文字（文字在药丸里，180ms 缓动），不再用图标下方 11sp 小字。
  新增 `ActionChip` + `selector_action_chip`。
- **筛选焦点改走返回键**：分类条 ↑ → 返回键，返回键 → 右 → 筛选；不再从分类条直接 ↑ 到筛选。
- **播放控制条重排**：`暂停/播放` 放最前，`上集/下集` 紧随；`选集` 移到循环之后，
  `重播`（从头播放）从「更多」提到常用行；「更多」只留缩放/硬解/引擎/刷新等低频项。
  整行焦点闭环：左右到行尾不丢焦点，上下不再跳到不可聚焦的进度条；
  「更多」↑ 展开二级行、↓ 回「更多」，二级行与主行焦点一致。
- **播放键行为可配**：设置 → 播放 → `播放键`：默认「暂停/播放」，可切「呼出菜单」
  （第一次 OK 弹控制栏，再按才作用到焦点按钮）。暂停按钮按 `playWhenReady` 更新，
  缓冲中不会闪成「播放」。
- **首页内容 ↑ 回分类条**：出现历史行后 `getSelectedPosition() <= 0` 失效，会直接跳到顶部源药丸；
  改成按第一个可见 child 的位置判断，有历史行时也能回到分类条。

### 1.9.4 增补（设置页信息架构）

- 设置页从「一长串同样的行」改成 **四个分区**：内容源 / 播放 / 系统 / 维护。
  分区标题 13sp、字距 0.08、`qbox_text_mute`，和可聚焦的行拉开层级（`SettingHeader`）。
- 行更紧凑：上下 padding 12 → 9dp，行距 12 → 8dp，720p 一屏从 6 行变 7 行；
  标签/值 18sp → 16sp，值仍锁定 `@color/text`，白药丸焦点时整体反色。
- 焦点仍是整行白药丸（系统里唯一的强焦点语言），右侧「主页/重置/刷新」图标单独可聚焦。


### 1.9.2 增补（交互修正，以此为准）

- **继续观看不再丢**：`HomeActivity.onResume` 重新读 `HistoryDao.findRecent()`，
  冷启动、从播放页返回首页都能看到历史；行标题 `最近观看`。
  卡片改 16:9 剧照（`adapter_history.xml`）+ 蓝色进度条，与下面的 3:4 推荐海报区分，
  一行就能完整放下，不会把「更新推荐」挤到屏幕外。
- **tab 与筛选拉开层级**：分类 tab 17sp / 42dp，焦点 = 白药丸反色、当前分类 = 12% 白底；
  筛选药丸 13sp / 28dp，幽灵描边。tab 明显更重，筛选退到次级动作。
- **移动焦点不再切页**：删掉 `selectedPosition → pager.setCurrentItem` 的联动，
  方向键只移动焦点，OK 才切页；当前分类有独立的「淡白底」标记，与焦点分离。
- **统一点击语义**：首页点一次分类 = 进入该分类；点播页点一次 = 切页，
  再点一次当前分类 = 展开/收起筛选；筛选展开后焦点自动落到第一个筛选项。
- **焦点链路重排**：内容 ↑ → 分类条；分类条 ↑ → 筛选药丸（没有筛选项则回返回）；
  筛选 ↑ → 返回；筛选 ↓ → 分类条；返回 ↓ → 分类条。
  （1.9.5 调整为：分类条 ↑ → 返回；返回 → 右 → 筛选。）
  `CustomTypeView` 不再把 ↑ 当刷新（刷新改成长按），方向键不会被吃掉。
- **顶部滚动渐隐**：首页/点播内容区顶部 48dp 渐变，滚到一半的上排标题被盖住，
  不会再出现半截文字贴在分类条下面。
- **内容区高度修正**：vertical LinearLayout 里的 `match_parent` 改 `0dp + weight=1`，
  首页/点播/收藏/专题页底部不再溢出；筛选 / 网格能完整滚到最后一行。


### 1.9.1 增补（存档）

- **筛选不重复**：只保留顶栏「筛选」幽灵药丸（1dp 描边，焦点变白），

- 详情页预览窗 12dp 圆角 + 1dp 描边，未起播时显示海报占位。
- OSD 常用项合并成一行：`选集 上集 下集 倍速 音轨 字幕 视轨 片头 片尾 循环 详情 更多`；
  「更多」只剩 `缩放 硬解 EXO 刷新 重播 版本 解析`。字幕在控制条弹出时自动抬高（0.2）。
- 对话框（换源列表等）子文字加 `duplicateParentState`，焦点白底时文字同步变深，不再白字白底。

## 1. Token

| Token | 值 | 用途 |
|---|---|---|
| `qbox_bg` | `#0A0B10` | 页面基色；实际由 `bg_app` 渐变（`#0D0F15 → #05060A`）覆盖 |
| `qbox_line` | 白 12% | 细分隔线 |
| `qbox_text` | `#FFFFFF` | 标题、主文字 |
| `qbox_text_dim` | `#B9B9C4` | 次要信息（年份/地区/时钟） |
| `qbox_text_mute` | `#8A8A96` | 说明文字（导演/演员/简介） |
| `qbox_accent` | `#5B8CFF` | 进度、选中环、链接；**不用于大面积填充** |
| `qbox_focus_text` | `#0B0B0F` | 白药丸/白环上的文字 |

规则：

- 焦点 = **白色药丸/白环**（反色），文字变深；选中 = 2dp 蓝色环。
- 卡片圆角 12dp，海报 10dp，面板 14dp；焦点环 2dp（不再 3–4dp + 缩放）。
- 图标与文字同色（`app:tint="@color/text"`，selector 内含 focused → 深色）。
- 字号：页面标题 19sp 粗体、详情标题 32sp 粗体、行标题 21sp、正文 14–15sp、tab 17sp medium、筛选 13sp、时钟 15sp（`tnum`）。

## 2. 全局外壳

所有二级页面统一顶栏：`46dp 圆形返回箭头 + 19sp 粗体标题 + 右侧 dim 时钟`。

- 返回箭头：`ic_back.xml` + `selector_action_icon`（焦点变白底深色）。
- 时钟：`HH:mm` / `HH:mm MM/dd EEE`，`fontFeatureSettings="tnum"`，不再带背景板。
- 首页顶栏：logo + **配置名药丸**（点击换源、长按直接换配置）+ 右侧 5 个 46dp 圆形图标
  （搜索 / 直播 / 收藏 / 推送 / 设置）+ 时钟。**图标默认只显示图形，聚焦时在下方显示 11sp 文字说明**
  （标签行固定 14dp 高，出现/消失不引起跳动）。

## 3. 首页

- 导航行：**只列当前源的点播分类**（不再有「首页」占位 tab；它就是首页）。
  42dp 高、17sp medium；焦点 = 白药丸 + 深色文字，未聚焦 dim。
  点击进入点播分类页（单次点击 = 进入该分类）。
- 内容行：`最近观看`（16:9 剧照 + 进度条）→ `更新推荐`（3:4 海报网格）。
  行标题 21sp 粗体，与内容左对齐 32dp；冷启动/每次回首页都从历史库重新读取。
- 海报卡：海报 + 左对齐标题 + 一行灰色元信息（年份 · 备注，合并成一行），
  不再叠加彩色年份/评分/更新角标；焦点 2dp 白环。
- 内容区顶部 48dp 滚动渐隐，上一排被裁掉的半截标题不会贴在分类条下面。

## 4. 点播分类页

- 顶栏：返回 + 站点名 + **筛选幽灵药丸**（13sp / 28dp，1dp 描边；无筛选项时置灰显示「无筛选」）+ 时钟。
- 分类 tab：只有各分类（没有「首页」占位），42dp 高、17sp medium；
  焦点 = 白药丸 + 深色文字；当前分类 = 12% 白底，与焦点分离。
  **移动焦点不切页，OK 才切页**；再按一次当前分类 = 展开/收起筛选。
- 焦点链路：内容 ↑ → 分类条；分类条 ↑ → 筛选药丸（没有筛选项则回返回）；
  筛选 ↑ → 返回；筛选 ↓ → 分类条；返回 ↓ → 分类条。
  筛选展开后焦点自动落到第一个筛选项。
- 筛选行：chip 式纯文字，选中白字，未选 dim。
- 内容：5 列海报网格（`Product.getColumn`，32dp 边距 / 16dp 间距），滚动到底自动翻页。
- **分类 tab 常驻**：不再被内容网格当作 sticky header 隐藏（`TypeFragment` 不再 `setHeader`）。

## 5. 详情 / 播放

- 左侧 400×225dp 视频框（焦点可进入→全屏），右侧：32sp 标题、备注、
  `站点 · 年份 · 地区 · 类型` 合并 meta、`导演 ·` `演员 ·`、简介（最多 5 行）。
- 主操作行：白色「播放」药丸 + 简介 / 收藏 / 换源（暗色药丸）。
- 下方：线路 flag、清晰度、剧集、分段、快速搜索，均为横向列表。
- 详情页根布局用同一套渐变 + 当前海报氛围底图，文字区压暗，不再露出壁纸或死黑。

## 6. 播放 OSD

控制条只保留 **一屏放得下** 的常用项，其余收进「更多」，彻底去掉横向滚动：

```
标题
进度条（品牌蓝）
[选集] [上集] [下集] [倍速] [音轨] [字幕] [视轨] [片头] [片尾] [循环] [详情] [更多]   ← 常用行
```

- 「更多」只剩低频开关：`原始 硬解 EXO 刷新 重播 版本 解析`，按钮文字变「收起」；
  面板展开在常用行上方，不再挤占常用项。
- 焦点规则：进度条 ↓ → 常用行首项（无选集时退到「上集」）；次级行 ↓ → 常用行；常用行 ↓ 不越界。
  打开控制条时若目标项在次级行，会自动展开。
- 控制条弹出时字幕自动上移（`setBottomPaddingFraction(0.2)`），避免和按钮行重叠。
- 「详情」= Stats for nerds 面板（左上角，1s 刷新，再按一次关闭）：

```
QBox stats
Engine   EXO · 硬解 · Surface
State    PLAYING · 1.0x
Video    1440×810 · 25.00fps · SDR
Codec    avc1.640020 · 4.20 Mbps
Audio    mp4a.40.2 · 2ch · 44.1kHz · Passthrough
Output   Passthrough · Dolby Digital+
Net      8.4 MB/s
Buffer   12.3s
Source   cdn.example.com
```

- 加载态中央转圈下方显示实时带宽（`Traffic`），不再隐藏。
- 直播 OSD 同一套规则：常用行 `配置 首页 暂停 音轨 线路 换源 更多`，其余（引擎/解码/倍速/缩放/字幕/视轨/反色/跨屏）收进「更多」。
- 弹幕：入口与云搜全部移除（`loadDanmaku` 空实现，设置页入口隐藏）。

## 7. 其他页面

- 搜索：64dp 圆角搜索框、dim 分区标题、站点 chip 行（焦点白药丸），结果复用海报卡。
- 收藏：顶栏 + 结果标题 + 网格，进入后焦点直接落到第一张卡。
- 直播：左侧频道分组/列表改为单色，选中行为白药丸，数字键选台保留。
- 设置：分组卡片、12dp 行距、图标 `app:tint`；弹幕项隐藏。

## 8. 已知取舍

- 不使用 Compose / 动画库，转场仍交给系统，避免低端盒子掉帧。
- 首页没有 hero 大图：源的内容结构不稳定，hero 容易空窗；用「最近观看」+ 氛围底图承担"继续观看"入口。
- 网盘（夸克 / UC / 百度 / 阿里…）的登录列表由配置里的 spider 决定（`Cloud-drive`），
  壳只负责渲染结果；某个盘缺失是源的问题，不在壳里硬编码。
- 焦点态统一"反色药丸"，所以任何使用 `@color/text` 的控件必须同时挂
  `selector_item*` / `selector_chip*` / `selector_tab` 背景，否则白字会看不见；
  容器型行的子 TextView 需要 `android:duplicateParentState="true"`。
