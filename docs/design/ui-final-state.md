## 二、对齐 OK影视 的结构（实测基线）

- 首页：`[logo 源名] [日期时钟]` → `[首页][分类…]` → `[直播][搜索][收藏][推送][设置]` → 最近观看 → 更新推荐
- 分类页：tab 行 + **常驻三行筛选**（类型/年份/地区，来自该分类自己的 filters）+ 海报网格
- 详情页：封面预览 + 标题/站源/年份/地区/类型 + 导演 + 演员 + **内联简介** + `▶播放/简介/收藏/换源` + 线路 + 剧集 + 同名片源
- 播放器：顶部标题 + 底部 14 项控制栏 + 蓝色进度条

## 三、我们保留的 QBox 设计（不回退）

- 不显示分辨率、KB/s、站点数等技术信息；
- 控制栏用胶囊 + 渐隐蒙层 + 品牌蓝进度条（OK 是灰方块）；
- 详情页主「▶ 播放」按钮（OK 需要先点线路）；
- 海报卡片隐藏「评分：0」这类空信息；
- 首页顶栏渐隐，滚动卡片不再被硬切；
- 空状态按场景给不同文案（收藏 vs 分类）。

## 四、覆盖页面

首页 / 分类 / 搜索 / 收藏 / 跨源结果 / 设置 / 详情 / 点播播放 / 直播 / 推送，全部统一顶栏与交互骨架。
