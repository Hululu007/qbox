# QBox UI v2 规划（对齐 Netflix / Apple TV 的电视端体验）

日期：2026-10-28　状态：规划中 → 分阶段实施

## 一、问题清单（来自你的反馈 + 真机截图确认）

| # | 问题 | 现状 |
|---|---|---|
| 1 | 层级重复 | 顶部 logo 一行、标题「豆豆｜片单」又一行 |
| 2 | 入口重复 | 「直播」既有大磁贴又有 tab；「设置」同样两处 |
| 3 | 技术信息外露 | hero 副标题「49 个站点 · 6 路直播」对用户无意义 |
| 4 | 点播门槛 | 首页要先点「点播」磁贴才进入分类浏览 |
| 5 | 播放控制 | 暂停/进度/剧集等控制条设计粗糙，未对齐成熟播放器 |
| 6 | 磁贴占屏 | 6 个大磁贴占掉首屏一半，内容（最近观看/推荐）被挤到下面 |

## 二、设计原则（借鉴 Netflix / Apple TV / Disney+ 的电视端）

1. **内容优先**：首屏尽量让海报和"继续观看"露出来，导航压缩到一行。
2. **单一入口**：同一个功能只出现一次；能用导航表达的不再用大磁贴。
3. **不展示技术细节**：站点数、直播源数、jar 缓存这类信息只放在"自检"里。
4. **一次点击到内容**：进入应用后第一次按 OK 就能开始浏览分类/继续观看。
5. **焦点可见且不迷路**：任何可聚焦元素都有明确焦点态；导航区与内容区上下切换顺畅。
6. **播放器控制极简**：暂停时底部一条控制栏（进度 + 播放/暂停 + 快退/快进 + 剧集 + 字幕/音轨 + 倍速），5 秒无操作自动隐藏。

## 三、信息架构（v2）

```
┌────────────────────────────────────────────────────────────┐
│ ▶ QBox   豆豆｜片单                              12:06:49  │  ← 一行：logo + 品牌 + 当前站点 + 时钟
│ (点播) (直播) (搜索) (收藏) (设置)                          │  ← 一行导航胶囊（替代 6 个大磁贴 + 3 个 tab）
├────────────────────────────────────────────────────────────┤
│ 继续观看   ▷ 海报…                                          │
│ 更新推荐   ▷ 海报…                                          │
│ …                                                          │
└────────────────────────────────────────────────────────────┘
```

- **删除**：hero 标题行、hero 副标题（站点/直播数）、hero 三个 tab、6 个大磁贴。
- **保留**：最近观看 / 更新推荐等内容行；当前站点名以小号灰字放在品牌名右边（切换站点仍走菜单键）。
- 导航胶囊：`点播` `直播` `搜索` `收藏` `设置`，焦点白色药丸；`点播` 为默认焦点，按 OK 直接进分类浏览。
- 首页不再有"首页"入口（本身就在首页）。

## 四、点播页（VodActivity）

- 进入即展示分类 chips（热播电影/剧集/综艺/筛选/榜单）+ 海报网格，**默认焦点落在第一个分类**，不再需要额外点开。
- 若某站点无分类数据，回退到海报网格并聚焦第一个海报。

## 五、播放器控制（VideoActivity / Live 的 OSD）

参考 Netflix / Apple TV 播放器：

```
┌────────────────────────────────────────────────────────────┐
│ ‹ 返回                                                      │
│                                                            │
│                    （画面）                                  │
│                                                            │
│ 剧集名 · 第 x 集                                            │
│ ───────────────●──────────────────  12:34 / 45:00          │
│   ⏪10s   ▶/⏸   ⏩10s     剧集  字幕  音轨  倍速   下一集      │
└────────────────────────────────────────────────────────────┘
```

- 暂停时显示控制条，播放时 5 秒自动隐藏；任何按键呼出。
- 控制项顺序固定：快退 10s → 播放/暂停 → 快进 10s → 剧集 → 字幕 → 音轨 → 倍速 → 下一集。
- 进度条支持左右拖动（DPAD 左右在进度条上加减 10s）。
- 直播页控制条简化：频道列表 + 播放/暂停 + 线路，不含进度。

## 七、风险与回退

- 改动集中在 `activity_home.xml`、`HomeActivity`、`VideoActivity` 的 OSD 布局与 `view_control_*`；每阶段独立提交，出问题可单阶段回退。
- 大磁贴由 leanback `FuncPresenter` 行提供，删除时同步移除 `setFunc()` 的行注册，避免空行。
- 首页改动后 `HomeLayoutTest` 中的 hero 断言需同步更新（改为断言导航胶囊）。

## 八、不在本次范围

- 换皮成完全不同的信息架构（如左侧边栏）；
- 直播多屏/时移；
- 手机版 UI。

## 九、验收记录（真机 Sony BRAVIA 4K / Android 12）

- 首页：单行标题 + 胶囊导航 + 继续观看（带进度条）+ 更新推荐，无重复入口/技术信息/空行。
- 点播：默认焦点「点播」，一下进入分类浏览（筛选 chips + 海报网格）。
- 详情：预览显示影片画面（无灰色播放占位图），信息层级清晰。
- 播放器：暂停弹底部控制条（标题/进度/暂停/上集下集/字幕/音轨/原始/倍速），无分辨率与 KB/s。
- 直播：长按 OK 呼出控制条（频道名/时移/配置/线路/音轨/换源），无技术项。
- 自动化：scripts\test.cmd 全绿（配置 49 站点 / 兜底 / 直播解析 2650 频道 / 首页布局）。
- 发布：v1.5.3（arm64 + v7a）。
