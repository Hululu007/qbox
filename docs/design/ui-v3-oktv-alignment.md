# UI v3 规划：以 OK影视（com.fongmi.android.tv 5.1.6）为基线，叠加我们的设计

日期：2026-10-29　设备：坚果投影仪（Android 9，1920×1080，192.168.2.132）

## 一、基线从哪来

用户提供 `C:\Users\Q\Downloads\OK-TV.apk`，并指出投影仪上已装 OK影视（package `com.fongmi.android.tv`，versionName 5.1.6）。
本轮直接从投影仪抓取其真实界面作为"基础逻辑"基准：

- 首页：`docs/screenshots/oktv-home.jpg`
- 分类页：`docs/screenshots/oktv-category.jpg`
- 详情页：`docs/screenshots/oktv-detail.jpg`

## 二、OK影视 的界面骨架（实测）

### 首页
```
[logo] 老白TVBOX                                        13:30:59 10/29 周四
[首页] [电影▾] [剧集▾] [臻彩▾] [短漫剧▾] [动漫▾] [综艺▾] [纪录片▾] [音乐▾]
[直播] [搜索] [收藏] [推送] [历史] [设置]        ← 6 个方块功能入口
最近观看  ▷ 海报…
更新推荐  ▷ 海报…
```
要点：
1. 顶栏只有一行：logo + 源名 + **日期时间（含星期）**；
2. 第二行是「首页」+ 分类 tab（带 ▾），**分类直接暴露**；
3. 第三行是 6 个功能方块（直播/搜索/收藏/推送/历史/设置）；
4. 内容行（最近观看/更新推荐）在下方。

### 分类页
```
[首页] [电影▾(选中)] [剧集▾] …
[全部] [喜剧] [爱情] [动作] …          ← 类型筛选行（内联）
[全部] [2026] [2025] …                ← 年份筛选行（内联）
[全部] [大陆] [中国香港] …            ← 地区筛选行（内联）
海报网格（年份角标 + 更新至HD/HD + 片名）
```
要点：**筛选条件是常驻行**，不是藏在「筛选」按钮后面。

### 详情页
```
[预览]                片名
                      更新至HD
                      站源 / 年份 / 地区 / 类型
                      导演
                      演员（超出用 … 截断）
                      简介：一行文本（内联，不弹窗）
                      [简介] [收藏] [换源]
[夸父原1] [夸父智1] …  ← 线路
[第xx集 / 文件]        ← 剧集
```

## 三、我们当前与基线的差异（按优先级）

| # | 差异 | 处理 |
|---|---|---|
| A1 | 首页缺「首页」tab，缺 推送/历史 入口 | 首页改为 tab 行（首页 + 分类），功能入口补齐 6 个 |
| A2 | 首页日期时间只有时分秒 | 改为 `HH:mm:ss MM/DD 周x` |
| B1 | 分类页筛选条件藏在「电影筛选/电视筛选」后 | 默认展开类型/年份/地区三行筛选 |
| C1 | 详情页简介是按钮弹窗 | 改为内联一行简介 + 保留按钮看全文 |
| D1 | 播放控制栏 | 待抓取 OK 的控制栏后对齐（OK 暂停时也有独立控制条） |

## 四、实施顺序

1. **P1 首页骨架**：tab 行（首页 + 分类）+ 6 功能入口 + 日期时间；
2. **P2 分类页**：筛选行常驻；
3. **P3 详情页**：内联简介；
4. **P4 播放器**：对照 OK 控制栏补齐并统一视觉。

## 五、保留的 QBox 设计差异（不回退）

- 不显示分辨率、KB/s 等技术信息（OK 详情页会显示 7.2 MB/s，我们不显示）；
- 底部控制栏采用渐隐蒙层 + 品牌蓝进度条；
- 时钟/源名使用深色胶囊底，保证亮背景下可读；
- 海报卡片隐藏"评分：0"这类空信息；
- 详情页提供主「▶ 播放」按钮（OK 没有，需要先点线路）。

## 六、验证方式

- 投影仪（192.168.2.132）与电视（192.168.2.130）都可 adb 安装，逐屏截图对比；
- 每次改动后 `scripts\test.cmd` 保持全绿；
- 与 OK影视同屏对比时，同一部片、同一来源，比较交互路径步数。
